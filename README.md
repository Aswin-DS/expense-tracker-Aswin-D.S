# Expense Tracker

A responsive expense tracking web application built using HTML, CSS and JavaScript.

## Features

- Add / Edit / Delete transactions
-Dashboard overview — total balance, total income, total expense, and a chart
- Transactions page — full history grouped by date, with filters for month, type (income/expense), and category
- Expense/income charts
- Monthly report page — income, expense, net savings, and an expense breakdown by category for the current month
- Toast notifications for form validation errors
- Responsive design


## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js

##Getting Started

No build tools or dependencies to install — just open the app in a browser.

-Clone the repository:
   
   git clone <your-repo-url>
   cd <your-repo-folder>
   
-Open tracker.html directly in a browser, or serve it locally:

   python -m http.server 8000

##Usage

-Tap the + button to add a new transaction.
-Use the sidebar (or top tabs on mobile) to switch between Dashboard, Transactions, and Report.
-On the Transactions page, filter by month, type, or category, and toggle the chart view to see trends.
-Click the ⋮ menu on any transaction to view details, edit, or delete it.
